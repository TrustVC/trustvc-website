# TrustVC Website

This repository hosts the TrustVC website. Detailed documentation will be added soon.

## Getting Started

```bash
npm install
npm run dev
```

## Build & Deploy

```bash
npm run build
```

Deploy the contents of `dist/` with your preferred hosting provider.

## Tech Stack

- Vite + React
- Tailwind CSS
- Node.js 22+
